# RandPass 密码生成器（2026-11-24）

## 1. 需求

用户要求：托盘右键菜单 + 面板 ☰ 功能菜单各加一个 **RandPass** 入口；面板标题栏 ☰ 左侧
增加**钥匙孔图标**作为一键主入口。三处打开同一个 RandPass 窗口，功能照 RandPass Lite 截图：

- 左栏参数：密码长度（默认 14）、密码数量（默认 14）、七个复选（小写/大写/数字/两位数字概率/
  无类似字符/自定义字符 默认全勾选，照截图；自定义格式默认关）+ 格式下拉（两个预设）
- 底部「生成密码」→ 右栏列出 N 条密码；**双击某条 = 复制到剪贴板**（用户确认加）
- **参数持久化**（用户确认做）：下次打开保持上次参数

## 2. 参数与默认值（= 截图状态）

| 参数 | 默认 | 说明 |
|---|---|---|
| 密码长度 L | 14 | 范围 4–64 |
| 密码数量 N | 14 | 范围 1–100 |
| 使用小写字母 | 开 | a–z |
| 使用大写字母 | 开 | A–Z |
| 使用数字 | 开 | 0–9 |
| 两位数字概率 | 开 | 见 §3 |
| 无类似字符 | 开 | 候选集剔除 `1 l I 3 L` |
| 使用自定义字符 | 开 | 文本框默认 `@#$`，字符并入候选集 |
| 使用自定义格式 | 关 | 预设两个，见 §4 |

## 3. 生成规则（纯函数，探针全覆盖）

1. **候选集** = 勾选的类（a-z / A-Z / 0-9 / 自定义字符去重并入）；「无类似字符」开时剔除
   `{1, l, I, 3, L}`。候选集为空（极端勾选组合）→ 回退全集（自定义字符除外）。
2. **随机源**：`RandomNumberGenerator`（密码学安全、AOT 安全、无反射）。
3. **两位数字概率**：逐槽生成内容；轮到数字类且本槽不是最后一槽时，以 **25%** 概率
   放一个"双同数字"（`11/22/…/00`，d 随机 0–9）并占掉 2 槽；否则普通 1 槽。
   内容总长恒 = L（双同数字消耗 2 槽，不是加长）。
4. **自定义格式**（§4）作用于内容（L 字符），`-` 为连接符不占 L。
   生成流程：先生成 L 位内容（规则 1–3），再按格式插横断行。

## 4. 自定义格式（用户口述规则 + 截图反推）

- 语法：数字 = 固定段长，`*` = 弹性段，段间以 `-` 连接；**内容总长恒等于密码长度 L**
  （用户原话："自定义格式的总长度受限于密码长度"），显示总长 = L + 段数 − 1。
- `*` 的分配：`rem = L − Σ固定段`，多个 `*` **平分 rem、余数给第一个 `*`**。
  L=14 时：`4-*-4` → [4,6,4]（与 RandPass Lite 截图 `GNKR-3jYwZj-5yg9` 逐段吻合）；
  `2-*-4-*-2` → [2,3,4,3,2]。
- 边界：`rem < 0` 时弹性段取 0 并整段（连同相邻 `-`）删除；段全删光 → 退化为无格式生成。
- 预设只有两个：**`4-*-4`**、**`2-*-4-*-2`**。第三个（`[8-4-4-4-12]`）**用户明确放弃，不实现**。

## 6. 验证

- **新探针 PasswordProbe**：长度/数量精确；单一字符类约束；无类似字符剔除（大量生成 0 出现）；
  双同数字统计（开=大量生成必现、关=必不现）；自定义字符并入；格式三段/五段结构、内容恒 = L、
  横断数 = 段数−1；L < 固定和的退化路径；AOT 安全（无反射调用）。
- **DialogProbe**：窗口结构（标题栏/两个 NumericUpDown/六个复选/格式下拉两项/生成按钮/结果列表）；
  生成后行数 = 数量；双击复制走剪贴板断言；设置写回。
- **PanelProbe**：标题栏钥匙孔按钮存在且绑 `ShowRandPassCommand`；☰ 菜单含 RandPass 行。
- **ComProbe**：托盘菜单含 RandPass 项。
- **SettingsProbe**：RandPass 段 Clone/Sanitized 往返。
- 回归 10 套 + 产品 AOT 重建 + PortableCheck/UiAcceptance + 提交。
